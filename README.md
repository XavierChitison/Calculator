## 🧠 How It Works

The calculator uses JavaScript to capture the numbers and operations selected by the user.

When a calculator button is clicked, an event listener processes the user's input and updates the calculator display.

The application keeps track of the current values and selected mathematical operation. When the user selects the equals button, JavaScript performs the calculation and displays the result.

The clear function allows the user to reset the calculator and begin a new calculation.
